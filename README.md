# Catoshi Vault Rush — standalone website

Catoshi rides a gold token through varied hills, jumps and cable routes. Seeded routes travel through canyon, forest, quarry and mountain vault scenery, with active jumps over red-marked hazards. The web game includes mobile controls, the opening vault burst, backflips, sound effects and the supplied soundtrack. Practice is free. The daily holder leaderboard checks a pasted Solana address for at least **50,000 CATOSHI**, with no wallet connection
